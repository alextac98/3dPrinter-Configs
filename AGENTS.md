# Agent Notes

This repo contains personal Klipper/3D printer configs for my 3D printers.

Keep changes small and config-focused. Treat existing local edits as user work, and prefer the repo's current style for printer, macro, and host-specific files.

## Project Structure

There are three currently supported printers - Bullet, Hazard, and Spoiler. They share common macros in `Macros` directory.

The `firmware` directory contains klipper firmware make configs for different boards.
